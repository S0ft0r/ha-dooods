# Локальный Home Assistant App DOOODS2

В `local_apps/dooods2/` находится установочный каталог Home Assistant App. Его slug — `dooods2` (три буквы `o`), поэтому он отличается от старого App `doods2` (две `o`) и может сосуществовать с ним. Отображаемое имя — **DOOODS2**.

Исходники backend находятся в `../analysis/application/`; каталог `application/` внутри App — синхронизированный build context. Скрипт синхронизации — `../analysis/scripts/package_local_app.py`, тесты — `../analysis/tests/`.

## Текущее состояние

App версии `0.1.15-dev` сохраняет HA Ingress для встроенного редактора. При запуске он выключает через собственный API Supervisor постоянную настройку `ingress_panel`, которая отвечает за отдельный пункт App в sidebar; отсутствие `panel_title` само по себе этого не делает. Если Supervisor API временно недоступен, App пишет предупреждение и повторяет попытку при следующем запуске. Основной экран профилей — admin-only панель интеграции **DOOODS**: один селектор камеры, встроенный ниже редактор и автоматическое назначение сохранённого профиля выбранной камере. API-ключ остаётся на стороне Home Assistant и не передаётся браузеру.

Редактор поддерживает профили, локальное изображение-подложку, временный JPEG-предпросмотр, полигональные зоны и связь `profile_id → opaque source_id`. Эта связь нужна только для повторного выбора кадра preview; она не сохраняет JPEG или `camera_entity_id`. Временные кадры хранятся в RAM. Также доступны локализованные подписи JPEG, фильтры по меткам настроенных моделей, объединение рамок, `showLabels` и отступ рамки.

Внутренний адрес `http://local-dooods2:8080` используется интеграцией для API-вызовов из сети Home Assistant. Не открывайте его в браузере: интерфейс профилей работает через HA Ingress внутри панели DOOODS. Старое приложение со slug `doods2` и прежний App `doods2_overhaul` остаются отдельными записями Supervisor.

При установке нового slug Home Assistant может использовать отдельное хранилище `/data`; если в старом App есть профили `/data/profiles.json`, сделайте резервную копию и перенесите файл при необходимости. Для переноса preview-связей скопируйте также `/data/profile_sources.json`; он хранит только `profile_id → source_id`.

Для релизных пакетов, тестов и инструкций обновления см. корневой `README.md` и `CHANGELOG.md`. Docker-сборка, Supervisor API, Ingress и runtime Home Assistant проверяются на стенде, а не в этой рабочей среде.

Из корня проекта синхронизируйте App build context командой:

```bash
python analysis/scripts/package_local_app.py
```

Полные предыдущие архивы находятся в `../releases/`; общий release-builder собирает инкрементальные ZIP с изменениями интеграции и/или App.
