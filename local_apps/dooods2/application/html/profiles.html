Профиль

Профиль содержит упорядоченные зоны. Их порядок задаёт приоритет при совпадении детекции.

Зоны профиля

Первая зона в списке имеет наивысший приоритет. Если её фильтры не подходят, проверяется следующая.

Предпросмотр и полигон

При сохранении профиля выбранный источник будет запомнен только для предпросмотра.
Выберите временный кадр камеры или загрузите локальное изображение. Кадры камеры хранятся на сервере только в оперативной памяти и не добавляются в профиль.

Перетаскивайте белые точки выбранной зоны. Нажмите «Добавить вершину»: точки получат номера, а на сторонах появятся маркеры «+». Нажмите маркер на нужной стороне — новая вершина встанет между её концами; затем её можно перетащить. Кадр камеры хранится на сервере только в RAM и не сохраняется в профиль; локальная подложка остаётся только в браузере.

Настройки выбранной зоны

Сначала выберите или добавьте зону.

Метки и пороги уверенности

Список ограничен метками всех настроенных моделей. Для каждой метки задайте порог уверенности от 0 до 100%; свободный ввод пользовательских меток пока не поддерживается.
